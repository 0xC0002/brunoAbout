# Bruno Antunes — Portfólio

Página única, responsiva e organizada em arquivos separados.

## Estrutura

```text
bruno-portfolio-v3/
├── index.html
├── styles.css
├── script.js
└── assets/
    ├── avatar.png
    └── curriculo-bruno-antunes.pdf
```

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3
- Bootstrap Icons

O Bootstrap é usado como base do grid responsivo e o visual específico permanece no `styles.css`.

## Currículo

O botão de currículo aponta para:

`assets/curriculo-bruno-antunes.pdf`

Coloque o PDF do seu currículo nessa pasta com esse nome para ativar o download.

## Manutenção

- Conteúdo: `index.html`
- Visual: `styles.css`
- Animações: `script.js`
- Imagens: `assets/`
